# Literature reference values

`raw/` contains the machine-readable result tables used in the comparison,
`transcribed/` contains the Foodmart values transcribed from Table B.15, and
`processed/` contains the normalized reference tables generated by the
evaluation scripts.

The source material was obtained from:

- [SPRP-SS repository](https://github.com/katrinhessler/SPRP-SS) and the
  [University of Mainz benchmark page](https://logistik.bwl.uni-mainz.de/research/#benchmarks)
  for the Heßler--Irnich result tables;
- the [Wahlen--Gschwind detailed results](https://wiwi.rptu.de/fgs/logistik/obp-bpc-detailedresults)
  for Henn--Wäscher and the Wahlen--Gschwind geometry of Muter--Öncan;
- [Wahlen (2026)](https://doi.org/10.1016/j.ejor.2025.08.055), Table B.15,
  for Foodmart;
- the [Briant et al. benchmark page](https://pagesperso.g-scop.grenoble-inp.fr/~cambazah/sequencing/)
  for Kris.

Run the following commands from the repository root to rebuild the processed
tables and the comparison:

```bash
python experiments/evaluation/02_prepare_literature_references.py
python experiments/evaluation/03_compare_vbs_to_references.py
```

Older source material and the original acquisition manifest are retained under
`legacy/`.
