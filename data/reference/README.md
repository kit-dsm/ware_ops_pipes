# Literature reference values

`raw/` contains the published machine-readable result tables used in the
comparison. `transcribed/` contains the Foodmart values transcribed from Table
B.15 of Wahlen (2026). `processed/` contains the normalized tables generated by
the evaluation scripts.

| Benchmark set | Reference values used | Source |
| --- | --- | --- |
| SPRP and SPRP-SS | Exact objective values reported by Heßler and Irnich | [SPRP-SS results repository](https://github.com/katrinhessler/SPRP-SS), [doi:10.1287/ijoc.2023.0075](https://doi.org/10.1287/ijoc.2023.0075) |
| BahceciOencan | Optimal-policy results reported by Heßler and Irnich | [University of Mainz benchmark page](https://logistik.bwl.uni-mainz.de/research/#benchmarks), Technical Report LM-2022-03 |
| HennWaescher and MuterOencan | Detailed result tables of Wahlen and Gschwind | [RPTU detailed-results page](https://wiwi.rptu.de/fgs/logistik/obp-bpc-detailedresults), [doi:10.1287/trsc.2023.1198](https://doi.org/10.1287/trsc.2023.1198) |
| Foodmart | Proven-optimal values in Table B.15 of Wahlen (2026) | [doi:10.1016/j.ejor.2025.08.055](https://doi.org/10.1016/j.ejor.2025.08.055) |
| Kris | Detailed lower-bound, upper-bound, and optimal-value tables of Briant et al. | [benchmark page](https://pagesperso.g-scop.grenoble-inp.fr/~cambazah/sequencing/), [arXiv:2303.17834](https://arxiv.org/abs/2303.17834) |

Run the following commands from the repository root to rebuild the normalized
tables and the comparison:

```bash
uv run --frozen python experiments/evaluation/02_prepare_literature_references.py
uv run --frozen python experiments/evaluation/03_compare_vbs_to_references.py
```

The published result files retain their source terms. The Foodmart CSV records
the values transcribed from the cited table and identifies the source in its
metadata. Consult the cited sources before redistributing their result data.
